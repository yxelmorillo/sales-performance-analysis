# Data Dictionary

This document describes the primary datasets used in this business case.

---

# Invoice

Contains all customer invoices and payment information.

| Column | Description |
|---------|-------------|
| invoice_id | Unique invoice identifier |
| account_id | Customer account identifier |
| payment_date | Date when the invoice was paid |
| invoice_status | Invoice status (Paid, Pending, etc.) |
| invoice_amount | Invoice amount in the original currency |
| currency | Invoice currency |

---

# Opportunities

Represents CRM sales opportunities.

| Column | Description |
|---------|-------------|
| opportunity_id | Unique opportunity identifier |
| account_id | Customer account identifier |
| sales_rep_id | Assigned sales representative |
| Current_Stage2 | Opportunity stage after data cleaning |
| Actual_Close_date | Date when the opportunity was successfully closed |

---

# Sales_rep

Contains sales representative information.

| Column | Description |
|---------|-------------|
| sales_rep_id | Unique salesperson identifier |
| sales_rep_name | Salesperson's full name |

---

# Exchange_rates

Monthly exchange rates used to standardize revenue into USD.

| Column | Description |
|---------|-------------|
| currency | Currency code |
| rate_date | Exchange rate reference date |
| rate_to_usd | Exchange rate to USD |

---

# Derived Business Metrics

The following metrics were created during the analysis.

| Metric | Description |
|---------|-------------|
| First Payment | First successful payment made by a customer |
| First Payment USD | First payment converted to USD |
| Customer Lifetime Value (LTV) | Total historical revenue generated by a customer |
| Customers Acquired | Number of customers whose first payment occurred during the evaluation period |
| Initial Revenue | Sum of customers' first payments |
| Total LTV | Total lifetime value generated by acquired customers |
| Average Customer LTV | Average lifetime value per acquired customer |

---

# Evaluation Period

The analysis considers customers whose first successful payment occurred between:

- November 1, 2025
- January 31, 2026

All monetary values are standardized to USD before performing the analysis.
